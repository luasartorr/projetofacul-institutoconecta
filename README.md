# projetofacul-institutoconecta
Projeto acadêmico do Instituto Conecta desenvolvido com HTML, CSS e JavaScript.


## Acessibilidade

O projeto Instituto Conecta adota práticas de acessibilidade web, incluindo HTML5 semântico, landmarks estruturais, navegação por teclado, foco visível, atributos WAI-ARIA e contraste de cores baseado nas diretrizes WCAG 2.1.

Também foram aplicados textos alternativos nas imagens, associação entre labels e campos de formulário, mensagens de validação acessíveis e suporte à preferência por redução de movimentos.
